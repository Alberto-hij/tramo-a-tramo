# Tramo a Tramo

Calculadora del **Impuesto Ficticio sobre la Renta Universitaria (IFRU)**, un impuesto inventado para una práctica docente.

- Calcula base liquidable, cuota íntegra, deducción por alquiler, cuota líquida, tipo medio y tipo marginal.
- Explica cada paso del cálculo y muestra el desglose por tramos.
- Incluye la comprobación de los 10 casos de prueba de la práctica.

Es una sola página (`index.html`) sin dependencias: se abre en cualquier navegador y funciona sin conexión.

> El IFRU no existe: esta calculadora no sirve para calcular ningún impuesto real.
